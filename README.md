# 现代社会系统设计构想

这是一个长期迭代的制度设计项目。各子系统可以分别讨论、修正，再检查它们之间的关系；仓库不预设一套已经确定的社会制度答案。

**当前状态：讨论稿。**第一个有实质内容的子系统是[教育系统设计构想](教育系统/README.md)。其他模块目前仅建立目录入口，尚未形成方案。本仓库内容不是已经实施的制度、法律意见或经过效果验证的政策。

## 阅读与修订约定

每个子系统先明确目标、权责、资源与约束，再记录方案方向和未决问题。跨系统关系应逐项校验，不能因一个子系统内部看似成立就假定整体可行。

文档须区分**已采用的工作前提、方案推演、待验证判断、未决问题**。本仓库所说的“共识”仅指本轮讨论采用的工作前提，不表示社会共识。新增事实、案例或效果判断，应注明来源和适用范围。

教育部分依据当前任务明确列出的议题和可读取的《教育蓝皮书评析》最近五轮对话整理。更早对话目前不可读取，因此具体算法、金额、阈值与法律路径没有被写成既定结论。
