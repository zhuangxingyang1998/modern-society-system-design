# 现代社会系统设计构想

这是一个长期迭代的制度设计项目。各子系统可以分别讨论、修正，再检查它们之间的关系；仓库不预设一套已经确定的社会制度答案。

**当前状态：讨论稿。**第一个有实质内容的子系统是[教育系统设计构想](教育系统/README.md)，其中 10–14 岁课程、组织、空间和支持已有第一版框架。公共财政、社会保障、空间与住房已有与教育相关的初步原则；其他模块仍是目录入口。本仓库内容不是已经实施的制度、法律意见或经过效果验证的政策。

## 阅读与修订约定

每个子系统先明确目标、权责、资源与约束，再记录方案方向和未决问题。跨系统关系应逐项校验，不能因一个子系统内部看似成立就假定整体可行。

文档须区分**已采用的工作前提、方案推演、待验证判断、未决问题**。本仓库所说的“共识”仅指本轮讨论采用的工作前提，不表示社会共识。新增事实、案例或效果判断，应注明来源和适用范围。

教育部分依据可读取的《教育蓝皮书评析》对话和后续提供的整理材料增量修订。部分更早讨论与压力测试的原始输入无法在本仓库独立复核，因此具体算法、金额、阈值与法律路径不能视为既定结论。
