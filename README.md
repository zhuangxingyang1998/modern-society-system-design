# 分布式教育体系：制度构想（讨论稿）

这是一份可持续修订的教育制度设计底稿，讨论 **0–6 岁儿童发展服务**与 **6–12 岁基础教育**。核心设想是：儿童的基本权益和必要信息能够跨地区、跨机构连续承接；具体服务由多元机构分散提供；家庭有真实选择；政府守住儿童权益和基础教育的底线，并在合格供给不足时兜底。

**状态：讨论稿，不是已经实施的制度、法律意见或效果已验证的政策。** 本仓库把本轮讨论形成的方向与尚需设计、验证的问题分开记录。这里的“共识”只表示这轮讨论采用的工作前提，不表示社会共识。

## 已形成的主要方向

- **0–6 岁：**全国统一的是儿童发展协议与信息承接规则，机构运营保持分散；社会力量主导服务供给，政府对服务缺口和儿童权益兜底。
- **6–12 岁：**小学提供普遍可获得的基础教育，不以小学表现决定下一阶段的升学机会；家庭可跨机构择校。
- **资金：**用 E 表示每名儿童的基础教育额度，用 P 表示特定学校的选择溢价，用 D 表示针对不利条件的纠偏资源。具体金额、出资方式和分配公式尚未确定。
- **招生：**设统一公共招生竞价平台，公开容量并执行共同规则；平台的具体竞价、排序和保护机制仍需设计。
- **供给：**学校自主决定容量与扩张。特定学校稀缺不等于基础教育稀缺；政府负责确保儿童在合理距离和成本内有合格教育可获得。
- **监管：**低摩擦、可核验的硬准入守安全与最低教育义务；学校软质量主要由信息透明、家庭选择和机构内部治理发现，政府不发布学校综合优劣排名。

## 材料边界
