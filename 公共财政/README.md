# 公共财政｜初步原则与待讨论

本模块已有与教育相关的初步原则，完整筹资、预算和转移支付方案仍待讨论。

税源与支出不一一绑定。空间税、所得税、消费税、企业税等进入统一公共财政体系；UBI、教育 E、医疗、养老和地区均衡分别按各自制度规则获得资金，不机械依赖某一税种当年收入。

全国教育权利和最低服务一致，合理服务成本可因地区不同。E 决定教育服务需要多少钱，不决定当地必须自行承担多少；发达地区可以成为净贡献者，结构性高成本地区可接受转移支付。参见[教育资金与配置](../教育系统/资金与配置.md)。

税基、税率、财政层级、均衡公式、预算约束及转移支付程序尚未确定。这些是讨论中的制度方向，不是现行财政制度或效果验证结论。
