# 初等教育｜基础能力、逐步自主与自由择校

## 小学阶段的定位

小学提供每名儿童都应获得的基础教育。当前方案方向是：**小学就读学校及其表现不决定下一阶段的升学机会**。这意味着小学不以“名校升学率”作为制度目标。下一阶段如何录取、如何避免隐性筛选，尚未在本轮讨论中解决。

6–10 岁是基础能力成形期；10–14 岁逐渐增加自主探索。两者是发展任务的连续变化，**12 岁不是硬分界**，也不直接规定某个年龄必须进入哪类学校。0–6 岁的儿童已通过日常生活开始学习边界、轮流、规则、选择与后果。

## 国家框架、教师与 Base OS

全国统一儿童发展目标、能力框架与教师责任框架，不统一教材、教学法和课程进度。建议面向教师建立《基础教育发展与教学框架》，给出发展路径、教学参考、观察与诊断参考：**国家定义尺度，教师保有教学判断与执行的自主权**。

Base OS 是全国统一联网、跟随儿童长期更新的能力状态系统，不是教材或教师填写的成绩单。6–10 岁重点涵盖语言理解与表达，数量、关系与基本逻辑，观察、探究与证据意识，自我管理，学习能力及基本共同生活能力。教师提交观察与证据，但不能单方面修改最终状态；评价不用作下一阶段升学筛选，也不进行学生排名。具体见[Base OS 与评价](../Base%20OS与评价.md)。

教师由学校雇佣，专业责任来自教育系统：主责教师按儿童承担长期教育连续性责任，共享或专业教师按领域承担责任。资格入口保持低门槛，能力主要由真实实践和市场长期筛选。具体见[教师体系](../教师体系.md)。

6–10 岁课程以不同活动所需的注意力组织时间，并每天留出共同体时间处理真实发生的冲突、规则与责任；具体见[课程组织](../6-10岁课程组织.md)。

## 家庭选择与共同招生规则

家庭原则上自由选择小学，不受固定学区或行政区边界锁定。面向所有学校的入学申请进入统一公共平台；学校公布可提供的容量，家庭可填写多个学校，并对不同学校分别表达可接受的 P／预算。平台按统一、公开、可审计的市场出清与志愿规则匹配，**不以随机抽签作为主要超额分配方式**。多校志愿排序、同价和边界情况、候补、违约、未匹配学生及具体出清算法见[未决问题](../未决问题.md)。

主要竞价在一个教育阶段入学时完成：匹配后儿童与学校原则上在该阶段稳定绑定，P 一次确定，不因学校后来更热门而每年重新竞价。家庭可一次或分期支付；分期只是现金流安排。儿童转学时，尚未使用的 E、D 跟人走，P 跟获得特定学校学位的择校行为走。主动转入更高 P 学校原则上须补足选择溢价，不能用先入低 P 学校再转学规避价格；非家庭主动迁移可另设例外。具体差额折算、分期违约和学校退出结算仍待设计。

自由择校不是每个家庭都能进入同一所学校。公共承诺应是儿童在合理距离与成本内**至少能够获得合格的基础教育**。

## 学校与政府的分工

学校在硬底线内决定教学特色、人员配置、招生容量和扩张计划。政府不因热门学校 P 高而命令其扩张；要检查本地所有儿童在实际可达范围内是否有足够的合格学位，并在整体供给不足时负责补足。

读者可在[资金与配置](../资金与配置.md)查看 E/P/D 与招生平台的关系，在[学校市场与监管](../学校市场与监管.md)查看稀缺和监管边界。制度细节仍待设计的部分见[未决问题](../未决问题.md)。
