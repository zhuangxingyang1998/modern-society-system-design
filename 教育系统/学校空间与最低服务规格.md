# 教育系统｜学校空间与最低服务规格

## 从设施清单转向服务规格

公共教育系统不负责规定一所“优秀学校”应该拥有什么设施，只负责判断儿童是否实际获得最低合格教育服务。

因此不以“必须有400米跑道、标准礼堂、大型图书馆、若干专用教室”作为统一办学模板，而采用：

**政府规定学生必须稳定获得什么；学校和市场决定用什么空间、组织和设施实现。**

## 三类空间

### Home Studio：低周转、高归属

Home Studio 是稳定班级的专属物理基地，原则上不作为其他班级或模块的轮转教室。它用于长期归属、讨论、世界理解、个人工作、储物、作品保留、休息和共同体活动。可以比传统正面授课教室更紧凑，但不能因压缩面积而失去这些基本功能。

### 标准模块室：高周转、低排他

数学、语言、逻辑、信息判断等基础模块通常不依赖大量专用设备。模块室应尽量标准化、可快速重排，并在不同课程之间高频共享。

### 专业空间：高成本、按使用频率共享

实验、制作、艺术、音乐、体育等空间是否校内自建，由使用频率、设备要求、地区条件和市场方案决定。低频、高占地或昂贵设施可以由多个学校、城市公共设施或专业机构共享。

**功能越需要长期归属，空间越专属；功能越标准化，空间越共享；功能越低频且高成本，越适合区域共享。**

## 户外活动与操场

公共系统不强制学校拥有大型标准操场，但必须保证学生能够高频、低摩擦、真实地获得户外活动。

最终法规需要把“高频、低摩擦”进一步转化为可验证变量，例如：正常在校日最低可用户外活动机会、日常活动空间的最大合理转换时间、正常课表下覆盖全部学生的容量、学校对外部场地是否拥有稳定可执行的使用权、是否能支持 Base OS 所需基本身体活动，以及基础安全条件。

具体分钟数、转换时间和容量参数尚待研究。

大型田径场、足球场、游泳馆和专业球馆可以是学校自有资源，也可以区域共享。日常户外机会则不能完全依赖需要长距离交通或复杂预约的外部设施。

## 图书、餐饮、礼堂和其他大空间

同样采用功能而非房间清单监管：不强制传统大型图书馆，但学生必须稳定获得阅读、资料获取、信息检索和安静自主学习条件；不规定食堂具体形态，但必须有安全、卫生、容量足够的就餐解决方案；不要求覆盖全校人数的大礼堂，只要求必要的展示、交流和公共活动能够可靠发生；科学、艺术和制作以 Base OS 所需活动是否能稳定完成为判断依据。

## 最低教育服务规格

| 底线领域 | 公共系统判断的问题 |
| --- | --- |
| Base OS | 是否真实、持续提供共同底座教育 |
| 学习支持 | 持续需要出现时，是否存在正常教育时间内的有效响应路径 |
| 教师责任 | 是否有明确责任成人和模块责任教师，教师负荷是否符合劳动底线 |
| 连续性 | 转学、换教师、换周期时，关键教育状态和支持是否可承接 |
| 身体与户外 | 是否实际获得基本身体活动和户外活动服务 |
| 学习空间 | 是否安全、健康并能够完成相应教育活动 |
| 儿童安全 | 人员、环境和儿童保护达到硬底线 |
| 基本权利 | 隐私、知情、表达、申诉、纪律程序和教育不中断得到保障 |
| 数据真实性 | Base OS、支持、责任等关键记录不得伪造 |

## 只评合格，不评优秀

公共监管只回答“是否达到最低合格线”，不发布学校综合质量分数、星级或政府版优秀排行榜。各项硬底线原则上逐项判断，不能用其他项目的高分抵消严重不合格。

**资格监管回答能不能办；市场回答办得怎么样。**

## 合格判定

合格判定分三层：能直接量化或客观核验的条件采用硬规则；不仅看纸面设施，还检查学生是否实际获得服务；学校没有采用标准形式但能证明达到同样底线时，允许等效合规。

人工专业判断只应用于等效方案和边界案例，不应成为日常主观审批。人工决定必须说明具体未达到哪条底线、依据什么证据，并允许复核和申诉。可以设计 Safe Harbor：满足一套简单客观条件时自动视为合格，创新方案则证明等效服务。

## 学校内部组织不由教育系统设计

教育系统不规定学校必须设置校长、副校长、年级主任、学科组长等具体层级，也不规定管理岗位是否由普通教师兼任。学校自行决定内部组织、行政层级、空间布局和人员组合，并自行承担由低效组织产生的成本。

公共监管只关注儿童服务、教师劳动、安全、数据真实性和公共资金边界。
