# 教育系统｜未决问题与验证议程

下表只列**已确定方向之下尚未形成可执行规则**的问题。现已明确：12 岁不是硬分界；全国统一儿童、能力与协议，不统一机构运营；10–14 岁已有第一版课程、组织、空间与支持框架；Base OS 是长期能力状态系统，教师不能单方改最终状态或决定 A；E 是基础采购价格，A 预测个体额外需要，D 修复系统结构；E、A 跟儿童走，P 跟择校行为走；招生采用市场出清和多校志愿，随机抽签不作为主要超额分配机制；P 一次定价并在阶段内原则上锁定。P 进入公共共同资金池、不直接成为热门学校收入、不返现参与第二轮竞价；D 不机械等于当年 P 收入，同届须有实际受益机会。公共监管只评合格，不评优秀。**算法、金额、比例、阈值和程序仍待设计。**

| 议题 | 需要明确的问题 | 可行的下一步 |
| --- | --- | --- |
| 儿童发展协议 | 最小必要信息、记录者、访问权、更正与删除、跨机构移交如何界定？ | 先绘制儿童、家庭、机构与公共部门之间的信息流，再做隐私与误用审查 |
| 0–6 岁公共承诺 | 何种服务必须可获得？“社会力量主导”与政府兜底的界线在哪里？ | 分情境定义服务缺口及响应路径 |
| 年龄与学制衔接 | 6–10 岁成形期与 10–14 岁过渡带如何跨学校组织？ | 先描述连续发展任务，再设计不以 12 岁硬切的学校路径 |
| 国家教学框架 | 《基础教育发展与教学框架》由谁维护、怎样更新与纠错，如何保留教师自主？ | 做一份不绑定教材和课时的教师使用样章 |
| 教师资格 | 低门槛条件如何可靠验证基础认知、沟通、组织与儿童安全？其他行业人员如何进入？ | 设计最小资格核验与实践支持路径 |
| 主责教师负荷 | 15–18 人研究参考在何种儿童需要与学校条件下适用？标准责任人数、超额补偿梯度如何设定？ | 结合实际工作量与儿童支持需求作情景研究 |
| 专业教师负荷 | 各专业类别的标准责任人数、超额递增补偿及与主责教师交接如何确定？ | 分专业类别做简单基准，不建复杂日常公式 |
| 教师收入 | 当地社会中位数采用何种口径？高责任、高能力和稀缺专业如何获得更高收入？ | 对照生活成本、劳动力市场与学校预算测算 |
| E 地区成本与校准 | 合理成本区间、外部价格锚点、调整周期和供给安全带如何设定？ | 分离筹资与使用端，做地区成本和供给模拟 |
| A 预测与治理 | 状态、轨迹、支持与响应如何预测后续额外需要？误差、纠错、申诉与防套利如何处理？ | 建立可解释样例，核验正常状态下持续支持的需要 |
| P 的阶段锁定与支付 | 分期年限、支付违约如何处理？学校中途退出时如何结算，极端情况是否重新匹配？ | 在入学一次定价原则下设计现金流与例外程序 |
| D 结构工具与时间责任 | 联合触发条件、同届投入比例和完成时限、工具选择与改善核验如何规定？ | 按席位、教师、专业设施和可达性缺口模拟，不设个人现金额度 |
| 公共招生平台 | 多校志愿如何排序？同价或边界情况、候补、违约和未匹配学生如何处理？具体市场出清算法如何设计？ | 在市场出清方向下建立公开规则样例并模拟 |
| 转学结算 | 主动转入更高 P 学校时补完整差额还是按剩余学制折算？学校倒闭、政府强制迁移等非主动转学如何例外？ | 分主动与非主动情形模拟 E 未使用部分、A 预测承接与 P 差额结算，并另行处理 D 项目合同 |
| Base OS 能力表达 | 已提出六个 6–10 岁重点领域；各领域发展状态怎样表达、怎样与 0–6 岁协议衔接？ | 先做少量能力描述样例，再检验误读与污名化风险 |
| Base OS 证据与校准 | 多来源证据如何核验、处理冲突、跨年度承接和更正？少量低风险统一参考任务如何避免变成选拔考试？ | 设计可追溯的证据和复核流程，再用样本模拟 |
| 数据权限 | 家庭、儿童、主责教师、专业教师、学校和教育体系的具体视图及交接如何实现？ | 逐字段列出目的、访问权与审计记录 |
| 小学与下一阶段 | 如何保证小学评价不用于升学筛选，同时安排过渡带与下一阶段的容量和录取？ | 另行设计入口规则，不预设 12 岁切换 |
| 6–10 岁课程组织 | 短周期高频教学、大时段活动、动态分组和每日共同体时间如何在不同学校落实？ | 小规模排程与教学观察，核对教师注意力负荷 |
| 10–14 岁 Base OS | 十个共同领域怎样形成可执行的发展描述？ | 制作能力和证据样例，避免机械学科课时化 |
| 周期模块 | 最佳周期、常规模块规模、跨年龄边界如何确定？ | 用不同学校排程复核，参考人数和周期不作法定标准 |
| 支持与重新汇合 | 支持模块进入、退出和重新汇合参数如何设定？ | 模拟同目标、前置修补和桥接路径 |
| 模块级关系记录 | 最小字段、接口、核验与保存期限是什么？ | 记录主要模块、负责教师、支持类型和完成情况，不统一每日课表 |
| 最低服务具体阈值 | 户外机会、转换时间、容量、稳定使用权和安全如何核验？ | 按学生实际获得的服务检验 |
| Safe Harbor 与等效合规 | 客观条件、等效方案审核、理由证据和复核申诉程序如何制定？ | 对传统与创新方案使用同一底线 |
| 运营压力测试 | 1500 人模型的工时、空间、成本能否复算？不同规模和地区如何变化？ | 公开输入和计算表，开展敏感性分析，再与真实学校数据核对 |
| 14+ 完整制度 | 真实社会参与、学徒与机构实践、劳动保护、收入、学校控制权退出及下一阶段入口如何设计？ | 先确定责任与保护边界，再讨论课程、供给和资金 |
| 实际可达性 | 合理通勤、成本、特殊需要和地区差异如何定义？ | 以儿童为单位绘制可达学位，而非仅统计行政区平均值 |
| 学校准入与复核 | 硬底线的最小集合、新校区、并购和关键人员变化如何审核？ | 逐项检查必要性、客观性与可能的进入壁垒 |
| 信息公开 | 哪些事实公开有益，哪些会暴露儿童隐私或造成误导性排名？ | 做字段级公开与隐私设计 |
| 学校利润与外部化 | 怎样识别把成本转嫁给教师、儿童或社会？责任负荷、合格教育底线和利润如何一起核验？ | 建立可观察的负荷与服务指标，区分效率提升与责任转嫁 |
| 供给兜底 | 新进入仍不足时，政府何时采购、提供场地或直接办学？ | 建立明确的缺口触发与儿童即时安置规则 |
| 退出与承接 | 学校倒闭、严重违规或整改期间，在校儿童如何无缝承接？ | 设计过渡资金、学位安排和资料移交程序 |
| 效果验证 | 选择、价格、基础能力、可达性、儿童福祉是否真的改善？ | 先界定基线、指标与小规模试点评估方法 |

## 讨论次序建议

先定**儿童可获得的最低服务、教师责任与信息边界**，再设计 **Base OS 校准、A 预测、E 成本校准和 E/A/P/D 的资金边界与招生匹配**，随后检验 **学校经营、区域供给缺口与兜底**，最后设计扩展与试点。这是编排建议，不是已获验证的最优政策路径。

新增结论时，应记录它属于：用户明确选择、共同讨论形成的方案方向、分析推演，还是外部证据支持的判断。不能用模拟结果替代现实试点，也不能用个别学校的高 P 宣称整个地区缺少教育。
