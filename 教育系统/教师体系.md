# 教育系统｜教师体系

## 教师的身份与职责权威

教师由学校雇佣，却是教育系统履行儿童发展责任的专业延伸。其权威来自明确的教育职责，用于教学判断、共同生活中的规则维护与儿童支持；这种**职责权威**不是因教师身份而拥有的无限权威。

三方权责分别是：教师负责专业教学判断与教育执行；学校负责组织、雇佣、排程和服务生产；教育体系负责统一发展与责任框架、必要数据、财政资源及硬底线。建议建立面向教师的《基础教育发展与教学框架》，提供发展路径、教学参考、观察与诊断参考。国家定义尺度，不规定统一教材、教学法或课程进度。

## 低门槛资格与持续成长

教师资格主要验证基础认知、沟通、人际交往、组织能力及儿童安全底线，不以漫长师范学历路径作为唯一入口。其他行业的成年人可以转入教育职业。资格证明进入的最低能力与安全条件；更高的实际教学能力在真实实践、学校用人、家庭选择和长期声誉中形成与筛选，不由政府给教师逐人做综合优劣排名。

14–18 岁未来可以通过教育实习提前积累真实经验。实习的责任边界、监督、儿童保护和是否取得正式资格仍待设计；**实习不等于由未成年人独立承担主责教师职责**。

## 6–10 岁主责教师：按人承担连续责任

主责教师对一组儿童的整体 Base OS 发展、长期观察、共同生活与规则、家庭沟通以及所需资源协调负责。主责教师承担**教育连续性**，不要求亲自解决每个专业问题；遇到专项需要，应协调专业教师和其他支持。

工作量以“教育责任负荷”而非课时衡量。15–18 名儿童暂作为**标准主责人数的后续研究参考**，不是已经核定的法定人数或一刀切上限。超过经研究确定的标准可以存在，但应像超额劳动一样获得递增责任补偿。制度预期是让增聘教师通常比无补偿地加重现有教师负担更合算，同时允许特别有能力且自愿承担更多责任的教师获得更高收入；实际激励效果仍须检验。主责负荷及相关数据应向家庭透明；具体计数边界、补偿梯度与防规避办法待定。

## 共享与专业教师：按领域承担责任

专业教师可覆盖体育、音乐、艺术、科学实践，也可为数学、阅读、写作等提供专项支持。他们对**自己负责领域**的教学、观察和专业判断负责，向主责教师提供必要信息；不负责完整学生档案或通常由主责教师承担的家庭沟通。

不同专业类别应有不同的标准责任人数，避免用复杂的日常公式逐节课折算。超过相应标准责任人数时，同样给予递增责任补偿。哪些活动由共享教师、专业教师或主责教师承担，以及各类别标准人数，仍需实测与研究。

## 10–14 岁班导师与运行余量

10–14 岁可保留接近传统班主任的长期角色，通常由专业教师兼任，但职责权威有边界。班导师持续掌握学生整体教育状态，主动、周期性开展一对一接触，支持学生理解选择及后果，协调专业教师与资源，承担必要的家庭沟通、Home Group 和异常转介；不全面管理学生私人生活，也不替学生作低风险、可逆的选择。

这份长期关系责任须通过**降低相应直接教学负荷**获得时间，不能作为无偿附加工作。动态分组本身不必增加教师数，持续降低组规模才会显著抬高成本；小组支持是阶段性高资源状态。教师工时要为备课、反馈、Base OS 记录、替补和异常处理留余量，课程与空间也不能长期按理论 100% 负荷排满。人数及工时估算见[运营与成本压力测试](运营与成本压力测试.md)，均未形成编制标准。

## 收入与职业路径

标准责任负荷下，教师基础收入的制度目标是大致位于当地社会收入中位数附近或略高，保证正常体面生活；这不是已经测得的薪酬水平，也不是一个固定全国工资数。高责任、高能力或市场稀缺的专业能力可以带来显著更高收入，优秀教师不应只能转入行政岗位才涨薪。

合理利润与教师收入可以并存。学校可提高经营效率，但不能靠隐蔽扩大教师责任人数、削弱儿童支持或把成本转嫁给社会来降本。标准负荷、超额补偿和公开数据需要相互校验。

## 与 Base OS、A 的边界

教师提交观察、判断、学生作品、任务证据及已采取支持措施，可指出需要额外支持的儿童；教师不能单方面修改 [Base OS 最终能力状态](Base%20OS与评价.md)，也不能直接决定 [A 额外资源](资金与配置.md)。教师和学校原则上看不到可用于套利的单个学生具体 A 财政预测权重，避免判断与收益直接绑定。正常专业判断误差用于长期校准，故意伪造数据或骗取资源应按违法行为处理。
