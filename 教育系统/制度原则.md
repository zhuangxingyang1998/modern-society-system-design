# 教育系统｜制度原则

## 1. 公共责任跟着儿童走

公共制度首先保证儿童能够实际获得安全、连续且达到最低标准的服务。机构是否受欢迎、是否扩张，不能替代对儿童可获得性的检查。家长承担选择与支付决策，但长期教育结果由儿童承受，因此公共底线仍有必要。

## 2. 统一权益与信息规则，分散组织服务

统一的是儿童跨机构承接所必需的协议、基本权益和公共规则；教学与照护方式、管理、人员组合和机构特色可以多元。全国统一信息不意味着全国统一办学主体，也不意味着所有儿童数据都应无差别公开。

国家统一儿童发展目标、能力框架和教师责任框架；不统一教材、教学法与课程进度。建议制定面向教师的《基础教育发展与教学框架》，提供发展路径、教学参考、观察和诊断参考。**国家定义尺度，教师掌握教学判断与执行的自主权。**

## 3. 进入机会应开放

硬准入应聚焦安全、儿童保护、最低从业条件及不可由事后市场纠正的基础义务，标准应客观、可核验、低自由裁量。符合标准者原则上可进入；不应以“本地学校已经够多”“办学特色重复”或预测生源不足来封锁新供给。

## 4. 政府守底线，市场发现差异

政府可以测量并公开必要的运行事实，处理严重违规和基础教育长期失效。学校的综合吸引力、教师是否优秀、何种课程风格更好，主要由家庭选择、学校招聘与内部管理、同行声誉等形成判断。政府不宜给学校或教师发布单一综合分数。学校受欢迎与 P 较高并不证明其教学效果更好。

公共监管只判断学校是否达到最低合格服务，不发布官方优秀、星级或综合分数。硬底线尽量写成客观条件和学生实际获得的服务；人工裁量主要用于等效方案和边界案例，须说明理由、证据并允许复核。最低服务规格见[学校空间与最低服务规格](学校空间与最低服务规格.md)。

教师由学校雇佣，却是教育系统履行儿童发展责任的专业延伸。教师的权威限于其教育职责，不是身份上的无限权威。学校负责组织与服务生产，教师负责教学判断，教育体系负责统一框架、数据、财政资源及硬底线。教师资格应尽量低门槛，实际能力由实践与市场长期筛选；详见[教师体系](教师体系.md)。

## 5. 保证合格教育可获得，不保证进入特定学校

学校自己决定办多大、是否开分校。政府应关注每名儿童在合理通勤和成本范围内能否进入合格学校，而非命令某所热门学校扩张。实际可达性比行政区边界更能描述儿童面临的供给；“合理”的具体阈值仍待确定。

## 6. 资金、招生与监管各有边界

资金概念固定为 **E/A/P/D**：E 是公共系统购买一份合格基础教育服务的基准价格；A 是 Base OS 对儿童未来额外教育资源需求的动态估计；P 是家庭为特定稀缺学校作出的选择溢价，进入公共教育共同资金池；D 用于修复系统性供给结构问题。**E、A 跟儿童走；P 跟择校行为走；D 不作为儿童的个人现金权益。**P 入学时一次确定、在该教育阶段原则上锁定，不直接成为热门学校额外收入，也不返还家庭再竞价。P 是 D 的重要资金来源和异常信号，但 D 不机械等于当年 P 收入；相当比例的同届教育纠偏投入应在该届仍处于同一教育周期时完成。具体金额、成本区间、预测算法、D 触发条件与结算程序仍待设计，详见[资金与配置](资金与配置.md)。

Base OS 是全国统一联网、随儿童长期更新的能力状态系统，不是教材、成绩单或升学筛选工具。教师提交多来源可校准的观察与证据，不能单方面改写最终状态或决定 A。学校采取的支持措施及儿童对此的响应是观察输入，不是服务报销凭证。数据全国统一而视图分权，教师和学校原则上看不到可用于套利的具体个体 A 财政预测权重；详见[Base OS 与评价](Base%20OS与评价.md)。

## 7. 合理利润与责任边界

私立学校可获得合理利润。公共系统购买的是合格教育服务，不报销学校实际成本；学校可以改进效率，但不得把成本外部化给教师、儿童或社会。教师责任负荷及超额递增补偿、Base OS 教育底线与家庭选择，共同构成经营约束；详见[学校市场与监管](学校市场与监管.md)。

教育系统不规定私立或社会化学校必须设置几层行政、多少校长或学科组长，也不决定管理岗位是否由教师兼任。学校自己组织人力和空间，并承担由低效组织产生的成本。公共监管仍检查儿童服务、教师劳动、安全、数据真实性与公共资金边界。

## 本轮修订的一个重要判断

较早一轮讨论曾把行政架构、教师实际水平和教育能力纳入较广泛的持续政府考核。后来明确采用**硬资格简单、社会资源易于进入；软质量尊重市场，不由政府逐人逐校评分**的方向。本轮进一步明确了教师职责、Base OS 多来源校准和 A 的财政隔离：正常的专业判断误差用于长期校准，不作为单次追责依据；故意伪造数据或骗取资源则应按违法行为处理。具体程序与法条仍待制定。
