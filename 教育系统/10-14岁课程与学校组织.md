# 教育系统｜10–14岁课程与学校组织

## 阶段定位

10–14岁是从儿童期向更高自主性的过渡带，不是12岁硬切的一道门。这个阶段不进行早期职业分流，而是在保留未来可能性的前提下练习选择、理解后果，并逐渐接触更大的社会世界。

学生仍需要稳定成人和稳定同伴，但学校对其私人生活和学习选择的直接控制应逐步收缩。导师不替学生做选择，而负责确保学生理解自己正在选择什么。

## 共同 Base OS

10–14岁共同底座不是传统学科清单，而是现代社会人的共同认知与生活能力。当前框架包括：

| 领域 | 核心目标 |
| --- | --- |
| 语言与表达 | 理解复杂信息、组织思想、清楚表达、倾听回应与基本论证 |
| 数量、关系、数据与模型 | 理解比例、概率、统计、变量、尺度与模型，并用数量检查现实 |
| 逻辑、证据与信息判断 | 分辨事实、观点、相关、因果、证据强弱、来源与误导 |
| 自然科学 | 建立基本自然模型，并理解观察、测量、实验、证据和模型修正 |
| 历史、社会与空间 | 理解社会变化、多因果、制度、利益、空间与资源条件 |
| 经济、资源与选择 | 理解稀缺、机会成本、价格、激励、劳动、企业与公共财政 |
| 法律、权利与公共制度 | 理解规则、权利、程序、权力边界、申诉与公共责任 |
| 身体、健康与关系 | 理解青春期、健康、自我照护、边界、同意、关系与求助 |
| 数字与 AI 素养 | 定义任务、选择工具、验证结果，理解数据、算法、隐私和 AI 局限 |
| 艺术、审美与设计 | 感知世界、表达自己、判断形式并理解文化 |

其中语言、逻辑、信息判断、数量判断、问题解决和元认知具有明显的横向属性，不要求都成为独立课程。编程不作为全民硬性 Base OS；数字与 AI 素养属于共同底座，编程和工具制造属于可选深化。

## 课程组织骨架

10–14岁课程先按五类时间组织，而不是把所有内容平均切成传统学科课时：

1. **基础认知高频存在。**语言、数学、逻辑和信息判断需要持续训练。
2. **世界知识主题化组织。**科学、历史、社会、空间、经济、法律、健康和数字世界可以围绕真实主题整合。
3. **综合项目周期性展开。**项目用于综合使用已有能力，不替代基础训练。
4. **个人深化稳定留时。**学生应有真正锁定的深化时间，同时保留接触陌生领域的探索时间。
5. **导师与共同体贯穿全程。**稳定同伴、主动导师联系、共同规则和公共讨论持续存在。

核心原则是：**基础能力系统训练 + 真实问题综合使用。**

## 稳定班级与 Home Studio

稳定班级保留，但不再决定所有课程进度。其核心功能是长期同伴关系、班导师、世界理解主题、共同体讨论、日常归属和部分项目。

可以继续称为“班级”，也可以在空间层称为 Home Studio。班级不再意味着所有学生全天一起上同一进度的课。

**班级负责我属于哪里；基础模块负责我现在需要学什么；项目与深化负责我和谁一起做什么。**

稳定班级原则上保持异质，不按 Base OS 水平把学生长期分成快班、慢班或重点班。

## 周期性模块分组

基础认知训练可按当前学习需要进行周期性模块分组。动态发生在周期之间，不是每天实时换组。

一个模块周期可以先以约6–8周作为设计参考。周期内学生、教师和学习目标基本稳定；周期结束后依据 Base OS、学生作品、教师判断和后续需要重新组合。

分组原则：

- 分的是当前学习任务，不给学生贴永久能力标签；
- 同一学生可在数学、写作、信息判断等不同领域处于不同模块；
- 常规模块不等于小班化，常规组仍可保持约20–26人的量级；
- 8–12人左右的小组属于阶段性高支持密度资源，不是默认教学规格；
- 相邻年龄在需要时可以共享模块池，但不要求按年龄彻底打散稳定班级。

动态分组本身不必显著增加教师数量：如果原本24人的固定班重新组合为24人的模块组，增加的是匹配度而不是教师工时。真正显著增加成本的是降低师生比，因此高支持小组必须用于真实需要。

## 支持模块与重新汇合

支持资源原则上优先发生在正常教育时间内，而不是要求跟不上者在放学后额外补课。需要支持的学生可以用支持模块全部或部分替代同期常规模块。

支持分为三种常见形态：

- **同目标支持：**学习与常规模块相同的核心目标，但节奏更慢、反馈更密；
- **前置能力修补：**短期修复阻碍当前学习的最小必要前置能力；
- **桥接模块：**当基础缺口较大时阶段性重建关键能力，再在明确节点重新汇合。

课程因此不能设计成没有余量的单线流水线。每个模块应区分：

- 必须达到的核心 Base OS 能力；
- 可伸缩的扩展案例与深化内容；
- 用于巩固、反馈、补缺、迁移和重新汇合的时间余量。

**路径可以不同，核心出口一致。**没有经历完全相同的案例不等于未达到共同底线。

## 一天的参考结构

以下只是用于验证可运行性的排程参考，不是全国统一课表：

| 时段 | 主要活动 | 组织方式 |
| --- | --- | --- |
| 到校短时段 | 整理、碰面 | 稳定班级 |
| 上午两个高专注时段 | 基础认知模块 | 周期模块组 |
| 午前长时段 | 世界理解主题 | 以稳定班级为主 |
| 午间 | 用餐与自由活动 | 自由社交 |
| 下午长时段 | 项目、深化、体育艺术、探索 | 按任务与兴趣组合 |
| 日末 | Home Group、导师、复盘 | 稳定班级 |

为降低模块空间和教师并发压力，可以让不同学生群错峰进入模块教学，而不是全校同时进入数学或语言课程。

## 班导师

10–14岁仍保留接近传统班主任的长期角色，但其职责边界改变。班导师通常本身也是专业教师，通过降低部分直接教学负荷承担长期学生关系责任。

班导师主要负责：

- 持续掌握学生整体教育状态；
- 主动、周期性一对一接触；
- 帮助学生理解选择、机会成本和后果；
- 协调专业教师、支持资源和必要家庭沟通；
- 维护 Home Group 的共同体与程序；
- 在安全、儿童保护和重大异常时启动转介。

班导师不是学生私人生活的全面管理者，也不替学生作低风险、可逆的个人选择。

## 模块级教育关系记录

全国系统不需要统一学校每天的具体课表。学校可以自由选择排课和运营软件，但应通过统一接口记录少量关键教育关系：当前周期学生参加的主要模块、模块类型与大致强度、负责教师、是否属于支持或桥接、实际参与和周期完成情况。

中央系统记录的是“学生在这个周期接受什么教育服务、由谁负责”，学校系统负责具体到天、教室、临时调课等日程执行。

## 经济约束

课程组织必须接受资源压力测试：不把动态分组等同于全面小班化；小组支持首先增加单位时间内的教育资源密度，而不是优先增加儿童学习时间；教师责任、课程和空间都应保留运行余量，不能长期按100%理论负荷排满；任何新增制度都应换算为每1000名学生增加多少教师小时、空间与运营成本。

当前讨论中的班级人数、周期长度或课时表均为设计参考，不是法定标准。
