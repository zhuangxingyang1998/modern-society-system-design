# 教育系统｜Base OS 与评价

## Base OS 是什么

Base OS 是全国统一联网、跟随儿童长期更新的**能力状态系统**。它描述儿童的发展状态，支持教师观察、教育连续性、最低教育底线与资源判断；它不是教材、统一教学进度，也不是由单个教师填写并立即生效的成绩单。

6–10 岁的重点能力包括：

1. 语言理解与表达；
2. 数量、关系与基本逻辑；
3. 观察、探究和证据意识；
4. 自我管理；
5. 学习能力；
6. 基本共同生活能力。

多数是个体成长能力，少部分涉及社会共同生活。教学时无需机械分开。具体能力描述、发展水平的表达形式和与 0–6 岁儿童发展协议的衔接尚待设计。

## 评价用途与禁区

小学评价用于理解儿童发展、识别支持需求和检查最低教育义务；**不用于下一阶段升学筛选，不进行学生排名，也不恢复高风险统一考试**。少量低风险统一参考任务可以作为校准来源，而非唯一结论或单次选拔门槛。

教师有观察与专业判断权，但不能单方面修改 Base OS 的最终状态。教师可提交观察、判断、作品和任务证据。系统结合主责教师与专业教师观察、学生作品与任务、跨教师和跨年度后续表现，以及少量低风险统一参考任务进行校准。最终状态的形成和更正必须可追溯；各来源如何加权、冲突如何处理、何时人工复核仍待定。

## 校准教师判断，不制造行政排名

单个教师对某名儿童前后判断不同，属于需要理解的正常专业误差，不因一次差异追责。长期、大量样本可以帮助识别某教师的判断倾向是偏高、偏低或相对准确，并为反馈与校准提供依据。**专业误差用于校准，教学能力差异交给学校用人与市场选择**；故意伪造记录或骗取资源则应按违法问题处理。

这不意味着用一个误差分数给教师排名。样本量、儿童起点、领域差异和观察条件都会影响判断；可用性、解释权与申诉程序需要另行设计。

## 全国数据、分权视图

全国统一的是长期可承接的数据状态和必要接口；不同角色只能看履责所需的视图：

| 角色 | 原则上的信息范围 |
| --- | --- |
| 主责教师 | 较完整的儿童教育发展状态，以承担长期连续性责任 |
| 专业教师 | 自己负责领域相关的儿童个人信息与证据 |
| 学校管理层 | 组织服务、排程和合规所需的信息；不因管理身份自动获得全部个人细节 |
| 教育体系后台 | 维护、校准 Base OS，并在有权限与程序约束下判断资源需求 |

教师和学校原则上看不到单个学生的具体 E 财政权重。视图分权不等于教师之间不能协作；必要交接应有明确目的和可审计记录。家庭与儿童的访问、更正、异议和隐私权细则仍待设计。

## 与 E 的关系

教育体系后台可依据长期 Base OS 数据、绝对能力目标、儿童自身的纵向发展、地区与全国参考分布，以及已经接受的支持强度，自动或半自动调整[随儿童流动的 E](资金与配置.md)。教师只负责发现和记录需求，不能把专业判断直接换成自己或学校可决定的财政额度。

上述列出的是**依据和权限边界**，不是已经确定的算法、权重、调整周期或金额。Base OS 的错误会影响儿童支持与财政安排，因此核实、更正、复核和申诉必须与技术设计一同完成。
