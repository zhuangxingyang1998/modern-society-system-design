# 教育系统｜Base OS 与评价

## Base OS 是什么

Base OS 是全国统一联网、跟随儿童长期更新的**能力状态系统**。它描述儿童的发展状态，支持教师观察、教育连续性、最低教育底线与资源判断；它不是教材、统一教学进度，也不是由单个教师填写并立即生效的成绩单。

6–10 岁的重点能力包括：

1. 语言理解与表达；
2. 数量、关系与基本逻辑；
3. 观察、探究和证据意识；
4. 自我管理；
5. 学习能力；
6. 基本共同生活能力。

多数是个体成长能力，少部分涉及社会共同生活。教学时无需机械分开。具体能力描述、发展水平的表达形式和与 0–6 岁儿童发展协议的衔接尚待设计。

10–14 岁共同底座已有第一版领域框架：语言与表达；数量、关系、数据与模型；逻辑、证据与信息判断；自然科学；历史、社会与空间；经济、资源与选择；法律、权利与公共制度；身体、健康与关系；数字与 AI 素养；艺术、审美与设计。它们是共同能力领域，不强制等量设置独立学科课时；各领域可执行的发展描述尚待制定。课程与组织关系见[10–14 岁课程与学校组织](10-14岁课程与学校组织.md)。

## 评价用途与禁区

小学评价用于理解儿童发展、识别支持需求和检查最低教育义务；**不用于下一阶段升学筛选，不进行学生排名，也不恢复高风险统一考试**。少量低风险统一参考任务可以作为校准来源，而非唯一结论或单次选拔门槛。

教师有观察与专业判断权，但不能单方面修改 Base OS 的最终状态。教师可提交观察、判断、作品和任务证据。系统结合主责教师与专业教师观察、学生作品与任务、跨教师和跨年度后续表现，以及少量低风险统一参考任务进行校准。最终状态的形成和更正必须可追溯；各来源如何加权、冲突如何处理、何时人工复核仍待定。

## 校准教师判断，不制造行政排名

单个教师对某名儿童前后判断不同，属于需要理解的正常专业误差，不因一次差异追责。长期、大量样本可以帮助识别某教师的判断倾向是偏高、偏低或相对准确，并为反馈与校准提供依据。**专业误差用于校准，教学能力差异交给学校用人与市场选择**；故意伪造记录或骗取资源则应按违法问题处理。

这不意味着用一个误差分数给教师排名。样本量、儿童起点、领域差异和观察条件都会影响判断；可用性、解释权与申诉程序需要另行设计。

## 全国数据、分权视图

全国统一的是长期可承接的数据状态和必要接口；不同角色只能看履责所需的视图：

| 角色 | 原则上的信息范围 |
| --- | --- |
| 主责教师 | 较完整的儿童教育发展状态，以承担长期连续性责任 |
| 专业教师 | 自己负责领域相关的儿童个人信息与证据 |
| 学校管理层 | 组织服务、排程和合规所需的信息；不因管理身份自动获得全部个人细节 |
| 教育体系后台 | 维护、校准 Base OS，并在有权限与程序约束下判断资源需求 |

教师和学校原则上看不到可用于套利的单个学生具体 A 财政预测权重。视图分权不等于教师之间不能协作；必要交接应有明确目的和可审计记录。家庭与儿童的访问、更正、异议和隐私权细则仍待设计。

## 教育响应与模块级关系记录

Base OS 除当前能力状态，还应观察发展轨迹以及儿童对不同教育支持的响应。学校采取了何种措施、支持强度及后续表现，是理解额外需要的证据，不是按实际服务逐项报销的凭证。

全国系统只需记录当前周期的主要模块、负责教师、支持类型和参与或完成情况等**模块级教育关系**；学校自主安排具体到天、教室与临时调课的日程。最小字段、核验、保存期限和访问权仍待设计。

## 与 E、A 的关系

[E](资金与配置.md)是同一合理成本区域内普通儿童获得合格教育服务的基准价格，不因个体 Base OS 短期波动改变。[A](资金与配置.md)由教育体系后台依据儿童的长期状态、发展轨迹、既有支持及响应，自动或半自动估计**未来额外教育资源需要**；教师发现和记录需求，但不能直接决定 A。

当前表现正常、却必须依靠持续额外支持才能维持正常的儿童，仍可能需要 A；只有在降低支持后发展仍稳定，A 才应逐步下降。正常短期波动可由 E 所购买的普通服务内部余量吸收。A 不是“Base OS 低就给钱”，也不是“学校做了多少就报销多少”。

上述列出的是**依据和权限边界**，不是已经确定的算法、权重、调整周期或金额。Base OS 的错误会影响儿童支持与财政安排，因此核实、更正、复核和申诉必须与技术设计一同完成。
