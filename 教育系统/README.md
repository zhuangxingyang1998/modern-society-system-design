# 教育系统设计构想

这是《现代社会系统设计构想》的第一个有实质内容的子系统。目录按服务阶段分类，但年龄不是学校制度的硬切线：0–6 岁已在日常生活中学习规则与后果；6–10 岁侧重基础能力成形；10–14 岁的课程、组织、空间和支持机制已有第一版框架。12 岁不是固定分界。14+ 的完整制度与高等教育仍待展开。

| 阶段 | 当前状态 | 文档 |
| --- | --- | --- |
| 学前教育与儿童发展（约 0–6 岁） | 日常生活中的早期发展与服务供给已有方向 | [查看](学前教育/README.md) |
| 初等教育 | 6–10 岁基础能力、教师与课程组织已有方向 | [查看](初等教育/README.md) |
| 10–14 岁过渡阶段 | 共同能力、周期模块、导师、支持与空间已有第一版框架 | [查看](10-14岁课程与学校组织.md) |
| 中等教育 | 10–14 岁框架已有；14+ 完整制度待讨论 | [查看](中等教育/README.md) |
| 高等教育 | 尚未形成方案 | [查看问题清单](高等教育/README.md) |

年龄段描述发展任务，不预先确定法定入学年龄、学制或阶段之间的唯一切换点。学前阶段也包含儿童发展与照护，不能简单等同于学校教育。
