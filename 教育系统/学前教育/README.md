# 学前教育（0–6 岁）｜统一承接，分散供给

## 已采用的方案方向

0–6 岁阶段拟有**全国统一的儿童发展协议**，使儿童在迁居、转换机构或由不同服务者接续支持时，不因机构边界而失去必要信息。社会力量主导具体服务供给，机构自主运营；政府制定公共底线，并对儿童权益和无法由社会供给满足的基本需求兜底。

这里的“协议”首先是信息与权责接口的构想，不等于全国统一课程、统一幼儿园经营，也不等于把儿童发展压缩为单一分数。

0–6 岁的教育并非从正式上课才开始。儿童已在日常共同生活中形成边界、轮流、规则、选择与后果的初步理解；这些发展任务应被看见，但不应被机械拆成学科成绩或提前升学筛选。

## 协议需要回答的接口问题

以下是**待设计问题**，不是已决定的数据字段或收集范围：

- 哪些信息对儿童发展支持的连续性确有必要，哪些不应收集？
- 信息由谁记录、核实、更正、保存和删除？家庭、儿童、机构、专业人员和政府各能看见什么？
- 机构更换、跨地区流动和服务退出时，怎样移交必要信息而不打断支持？
- 如何处理同意、隐私保护、错误记录、污名化和将发展信息用于招生筛选的风险？
- 协议怎样与健康、残障支持及教育服务衔接，同时保持各自责任清楚？

## 供给与兜底

社会机构可探索不同服务形式。政府要核查儿童是否**实际有服务可用**，不能仅凭“市场上有机构”判断供给充分。如果某地长期没有可达、安全、合格的基本服务，应先查清障碍与需求，再通过开放进入、资源支持、采购或直接提供等路径补足；具体工具及触发条件尚未定案。

政府兜底针对的是儿童的服务缺口，不是保障某一家机构维持规模或利润。机构的运营分散也不削弱儿童保护与基本安全要求。

## 与后续基础教育的衔接

儿童信息应能在升入小学后按照最小必要原则继续支持儿童，而不成为提前给儿童贴标签、划定学校等级或决定未来升学的依据。衔接方式、授权和使用禁区需要单独制定。
