# 中等教育｜10–14 岁框架与 14+ 待讨论

10–14 岁过渡阶段已形成第一版共同 Base OS、课程、稳定班级与周期模块、导师、支持、空间和最低服务框架，见[10–14 岁课程与学校组织](../10-14岁课程与学校组织.md)。12 岁仍不是硬切点；这一框架尚未经真实学校运行验证，不能据此宣称完整学制已定。

真正待展开的是 14+：真实社会参与、学徒与机构实践、劳动保护、收入、学校控制权继续退出、不同学习路径及下一阶段教育入口。14–18 岁教育实习只是一条可能经验路径，见[教师体系](../教师体系.md)，不是已定课程。

小学评价不用于下一阶段升学筛选；跨阶段容量、录取与资金执行细节仍需设计，不能直接预设 E/A/P/D、竞价或 Base OS 的全部执行规则。相关问题见[未决问题](../未决问题.md)。
