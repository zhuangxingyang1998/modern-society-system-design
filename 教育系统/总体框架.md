# 教育系统｜总体框架

## 方案要解决什么

本构想试图把三件经常被捆在一起的事拆开：

1. **儿童权益和公共底线：**每名儿童应能获得连续的发展支持与合格的基础教育。
2. **服务生产：**托育、发展支持和学校可以由不同机构以不同方式提供。
3. **资源配置：**家庭选择和服务需求传递供给信号；政府处理儿童权益、公共规则与系统性供给缺口。

“分布式、去解耦”在这里指权责分离，并非取消公共责任，也并非将儿童利益完全交给家长的支付意愿。

## 连续的发展任务与服务阶段

| 阶段 | 公共任务 | 分散提供的空间 | 待定边界 |
| --- | --- | --- | --- |
| [学前教育与儿童发展（约 0–6 岁）](学前教育/README.md) | 通过日常生活形成边界、轮流、规则、选择与后果；建立可跨机构承接的儿童发展协议 | 社会力量主导具体服务，机构自行运营 | 协议字段、保障强度、供给补足方式 |
| [初等教育](初等教育/README.md) | 6–10 岁基础能力成形，保障教育可获得性 | 教师在国家框架下自主教学，家庭择校，学校决定特色与容量 | 学校阶段切换、招生匹配与执行阈值 |
| [10–14 岁过渡阶段](10-14岁课程与学校组织.md) | 共同 Base OS、周期模块、稳定班级、导师和支持机制已有第一版框架 | 学校自主组织课程、人力与空间，逐步增加学生选择 | 模块、支持与空间参数仍需验证 |
| [中等教育](中等教育/README.md) | 10–14 岁框架已有，14+ 制度待展开 | 14+ 尚未讨论 | 真实社会参与、劳动保护与下一阶段入口 |
| [高等教育](高等教育/README.md) | 尚未讨论 | 尚未讨论 | 准入、供给与资助 |

**12 岁不是硬分界。**本轮对 0–6 岁、6–10 岁与 10–14 岁已有不同深度的讨论：10–14 岁的课程、组织、空间和支持机制已有第一版框架，但不是经学校运行验证的制度；14+ 与高等教育仍待设计。

全国统一的是儿童发展目标、能力框架与教师责任框架，不是教材、教学法或课程进度。面向教师的《基础教育发展与教学框架》是建议中的工具，用于提供发展路径、教学及观察诊断参考。参见[教师体系](教师体系.md)、[Base OS 与评价](Base%20OS与评价.md)、[6–10 岁课程组织](6-10岁课程组织.md)、[10–14 岁课程与学校组织](10-14岁课程与学校组织.md)、[学校空间与最低服务规格](学校空间与最低服务规格.md)及[运营与成本压力测试](运营与成本压力测试.md)。

公共监管只判断最低合格，不评价哪所学校更优秀；学校内部行政层级不由教育体系统一规定。课程、人力与空间方案必须接受经济压力测试，压力测试通过前不能宣称可规模化运行。

## 责任边界

| 行为者 | 本构想中的责任或自由 |
| --- | --- |
| 儿童 | 基本权益的承担者；制度评价以其实际可获得的服务与长期利益为准 |
| 家庭 | 在公共规则下选择机构或学校，表达对特色、距离与 P 的偏好 |
| 教师 | 依据统一尺度作专业教学判断与教育执行；提交观察和证据，不直接决定 Base OS 最终状态或 A |
| 服务机构、学校 | 雇佣和组织教师、生产服务、决定规模与是否扩张；遵守责任负荷、儿童权益与教育底线 |
| 公共平台 | 提供统一的必要信息、招生规则与可核查记录；不得自行把偏好信号伪装成质量评分 |
| 教育体系 | 定义统一框架、维护必要数据与 E/A/P/D 资源、执行硬底线和系统性可获得性责任，供给不足时兜底 |

## 工作前提与审慎之处

本轮讨论较清楚地支持：多元供给、家庭选择、学校容量自主、低门槛硬准入、市场主导软质量，以及“学校稀缺不等于教育稀缺”。这些是**方案方向**，尚非经实证检验的效果结论。

学校基础服务收入以随学生流动的 E 为核心；A 对应儿童自身额外教育资源需求，D 用于修复系统性供给结构，二者不等同。P 是特定学校的选择溢价，进入公共教育共同资金池，不直接增加热门学校的收入。私立学校可以获得合理利润，但不得把降本代价转嫁给教师、儿童或社会。资金与经营边界见[资金与配置](资金与配置.md)和[学校市场与监管](学校市场与监管.md)。

需要特别区分两个判断：一所热门学校名额少且 P 高，只能说明对该校的偏好或其稀缺；若可达范围内合格学位不足、儿童无法匹配或通勤成本异常，才构成政府需要处理的基础教育供给问题。高 P 本身不能单独诊断教育质量或区域缺口。

具体可执行规则见各专题；仍有争议或缺少证据的事项集中在[未决问题](未决问题.md)。
