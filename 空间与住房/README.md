# 空间与住房｜初步原则与待讨论

本模块已有空间税及教育空间成本的初步原则，完整空间与住房方案仍待讨论。

空间税反映空间稀缺和社会机会成本，进入[公共财政](../公共财政/README.md)，不与单一支出完全绑定。

教育 E 可以包含标准化合理空间负担，但不按学校实际昂贵选址成本报销。具体成本锚点和调整程序仍待设计，参见[教育资金与配置](../教育系统/资金与配置.md)和[学校空间与最低服务规格](../教育系统/学校空间与最低服务规格.md)。

教育资格与住宅所有权、户籍及学区房脱钩；地理接近只保留普通通勤便利价值，不产生特定学校法定优先权。合理可达性的具体阈值仍待制定。

空间税税基、评估、税率、使用权安排及住房保障仍未形成完整方案，不能将上述原则视为现行法规或已验证效果。
