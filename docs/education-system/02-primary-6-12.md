# 初等教育（6–12 岁）｜基础教育与自由择校

## 小学阶段的定位

小学提供每名儿童都应获得的基础教育。当前方案方向是：**小学就读学校及其表现不决定下一阶段的升学机会**。这意味着小学不以“名校升学率”作为制度目标。下一阶段如何录取、如何避免隐性筛选，尚未在本轮讨论中解决。

## 基础能力底线（Base OS）

Base OS 是对儿童应获得的最低基础能力的暂用名称。最近讨论以基础阅读、数学能力举例，强调政府关注的是长期、大量儿童未获得基础能力的失败情形，而不是给学校或教师排出最优名次。

它的学科范围、年龄节点、测量办法、支持性干预与申诉程序都尚未确定。尤其要避免把儿童当前困难直接归咎于单个教师，或把最低结果变成学校筛选学生的激励。

## 家庭选择与共同招生规则

家庭原则上自由选择小学，不受固定学区或行政区边界锁定。学校公布可提供的容量；统一公共招生竞价平台承载申请、必要信息和统一规则，并记录匹配结果。平台的具体竞价算法、优先次序、超额申请处理、反操纵措施，以及儿童无法匹配时的即时安排，均是[未决问题](../99-open-questions.md)。

自由择校不是每个家庭都能进入同一所学校。公共承诺应是儿童在合理距离与成本内**至少能够获得合格的基础教育**。

## 学校与政府的分工

学校在硬底线内决定教学特色、人员配置、招生容量和扩张计划。政府不因热门学校 P 高而命令其扩张；要检查本地所有儿童在实际可达范围内是否有足够的合格学位，并在整体供给不足时负责补足。

读者可在[资金与配置](../04-funding-and-allocation.md)查看 E/P/D 与招生平台的关系，在[学校市场与监管](../05-school-market-and-regulation.md)查看稀缺和监管边界。
