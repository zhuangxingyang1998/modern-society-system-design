# 99｜未决问题与验证议程

下表列的是本轮尚未形成可执行规则的问题。它们不因出现在仓库中就自动成为制度共识。

| 议题 | 需要明确的问题 | 可行的下一步 |
| --- | --- | --- |
| 儿童发展协议 | 最小必要信息、记录者、访问权、更正与删除、跨机构移交如何界定？ | 先绘制儿童、家庭、机构与公共部门之间的信息流，再做隐私与误用审查 |
| 0–6 岁公共承诺 | 何种服务必须可获得？“社会力量主导”与政府兜底的界线在哪里？ | 分情境定义服务缺口及响应路径 |
| E | 谁出资、按何地成本核算、何时随儿童流转？ | 做财政测算与地区成本情景分析 |
| P | 家庭如何表达 P；是否有上限或保障席位；如何避免家庭财力决定基础教育机会？ | 比较若干招生规则，模拟不同收入家庭的结果 |
| D | 纠偏对象是家庭、儿童支持需求、学校还是区域缺口？如何避免重复拨款或挤占？ | 先定义要纠正的具体不利条件，再设计拨付与审计 |
| 公共招生平台 | 志愿、竞价、排序、抽签、申诉、候补和未匹配儿童如何处理？ | 建立公开规则样例，用真实约束下的假设数据做模拟 |
| Base OS | 最低能力包括什么；怎样测量而不鼓励筛选、刷题或误罚？ | 将最低义务、支持措施和程序保障一起设计 |
| 小学与下一阶段 | 如何保证小学不决定升学，同时处理下一阶段本身的容量与录取？ | 单独设计 12 岁后的入口，不提前假定结果 |
| 实际可达性 | 合理通勤、成本、特殊需要和地区差异如何定义？ | 以儿童为单位绘制可达学位，而非仅统计行政区平均值 |
| 学校准入与复核 | 硬底线的最小集合、新校区、并购和关键人员变化如何审核？ | 逐项检查必要性、客观性与可能的进入壁垒 |
| 信息公开 | 哪些事实公开有益，哪些会暴露儿童隐私或造成误导性排名？ | 做字段级公开与隐私设计 |
| 供给兜底 | 新进入仍不足时，政府何时采购、提供场地或直接办学？ | 建立明确的缺口触发与儿童即时安置规则 |
| 退出与转学 | 学校倒闭、严重违规或整改期间，在校儿童如何无缝承接？ | 设计过渡资金、学位安排和资料移交程序 |
| 效果验证 | 选择、价格、基础能力、可达性、儿童福祉是否真的改善？ | 先界定基线、指标与小规模试点评估方法 |

## 讨论次序建议

先定**儿童可获得的最低服务与信息边界**，再定 **E/P/D 和招生匹配规则**，随后检验 **区域供给缺口与兜底**，最后设计扩展与试点。这是编排建议，不是已获验证的最优政策路径。

新增结论时，应记录它属于：用户明确选择、共同讨论形成的方案方向、分析推演，还是外部证据支持的判断。不能用模拟结果替代现实试点，也不能用个别学校的高 P 宣称整个地区缺少教育。
